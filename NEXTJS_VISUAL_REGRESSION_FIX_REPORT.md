# SOLID SCRAP OF THE NORTH
# NEXTJS VISUAL REGRESSION FIX REPORT

## 1. Root Cause Analysis

### The Problem
During the Vite to Next.js migration, the styling of the application broke completely (broken grid/flex layouts, collapsed sections, and unstyled typography). 

### The Cause
* **Tailwind v4 Configuration Mismatch**: Next.js 15 does not compile Tailwind CSS v4 natively without a PostCSS setup unless explicitly configured using experimental features. 
* **Missing PostCSS Compiler**: The workspace was missing the required dependencies `@tailwindcss/postcss` and `postcss`, and there was no `postcss.config.mjs` file in the Next.js project directory (`artifacts/solid-scrap`).
* **Result**: The `@import "tailwindcss";` directive in `globals.css` was ignored and omitted from the compiled CSS output, leaving the application rendered as unstyled raw HTML.

---

## 2. Evidence of Tailwind CSS Generation Failure

Before applying the fix, the compiled CSS file generated by Next.js (`layout.css`) was only **60,210 bytes** and contained raw directives instead of compiled utility styles:
```css
@import url('https://fonts.googleapis.com/css2?family=Alexandria:wght@200;300;400;500;600;700;800;900&display=swap');
@plugin "@tailwindcss/typography";
/* No Tailwind utility classes were generated! */
```

After installing PostCSS and `@tailwindcss/postcss`, the compiled CSS file size increased to **126,285 bytes** (exactly matching the original Vite-based production build size of ~126KB), and it contains all compiled Tailwind utility classes (`.flex`, `.grid`, `.text-center`, etc.).
